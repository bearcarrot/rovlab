# RoV LAB — Data Policy

> Last reviewed: 2026-10-02

## Purpose

RoV LAB combines game data, manually curated information, calculated statistics, heuristic analysis, community content, and AI-generated analysis.

This policy explains how those categories should be treated.

## Accuracy and Completeness

RoV LAB does not guarantee that all information is:

- Complete
- Error-free
- Current
- Correct for the latest game patch
- Applicable to every player, rank, role, or situation

RoV changes over time. Hero abilities, statistics, items, arcana, balance values, and gameplay interactions can change between patches.

## Curated Data

Curated data is information manually collected or maintained by the project.

Curated does not necessarily mean officially published by the game publisher.

The project should preserve the source and patch context whenever practical.

## Derived Data

Derived data is calculated from other information.

Examples include:

- aggregated statistics
- rank-weighted values
- calculated matchup scores
- counts
- rankings generated from project data

Derived values should not be described as direct official statistics unless the underlying source explicitly supports that claim.

## Heuristic Data

Heuristic data is produced using rules, assumptions, scoring systems, or estimates.

Examples include:

- fallback item recommendations
- draft recommendations
- counter scores
- risk labels
- matchup classifications

Heuristics can be useful but should not be represented as guaranteed outcomes.

## Patch Awareness

When data is patch-sensitive, the project should preserve patch/version context whenever possible.

Do not overwrite historical information simply because a newer patch exists if historical comparison is useful.

## AI-Generated Information

AI-generated output may:

- misunderstand context
- overgeneralize
- use incomplete project data
- produce incorrect conclusions
- become outdated as the game changes

Coach Ai should therefore be treated as an analytical assistant, not an official source of game information.

## Community Content

Comments, guides, votes, and other user-generated information remain community content unless independently verified.

User submissions should not automatically become authoritative game data.

## Data Changes

When changing important game data:

1. Verify the source.
2. Identify the relevant patch/version.
3. Check for duplicate or conflicting records.
4. Update the canonical dataset.
5. Preserve provenance.
6. Update documentation where necessary.

## Maintenance Priority

The following areas generally require frequent review because they are sensitive to game updates:

1. Hero statistics and patches
2. Items
3. Counters
4. Builds and arcana
5. Synergies
6. Matchups
7. Guides and insights

This list is a maintenance priority, not a gameplay ranking.
